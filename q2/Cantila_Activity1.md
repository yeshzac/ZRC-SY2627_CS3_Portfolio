1. Based on the inheritance hierarchy discussed in the video, the Programmer class derives from the Employee class, which in turn
derives from the Person class. Therefore, both Employee and Person are parent classes of the Programmer class.

2. If you were to add an Intern role, it should be placed as a subclass of the Employee class. This is because an intern is a type
of employee within a business structure. By inheriting from Employee, the Intern class would automatically gain all the shared
methods and properties defined in both the Employee and Person classes, while still allowing you to add specific attributes or 
behaviors unique to interns.
